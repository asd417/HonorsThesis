Learning generalized reactive policies using deep neural networks

DNN can learn and represent a Generalized Reactive Policy(GRP): Maps a problem instance and a state to an action, and that the learned GRP efficiently solve large classes of challenging problems. 

Compared to previous works: reduces dependence of learning on handcrafted domain knowledge or feature selection. Trained from scratch using a set of successful execution traces. 

They used Multi-headed convolutional neural network (supports the empirical findings of myself) for Action Probability and Plan Length prediction \cite{groshev2018learning}




Solving Sokoban with Forward-Backward Reinforcement Learning (also from Google)
\cite{shoham2021solving}

Sokoban is a sparse reward environment. So we used two networks: backward facing and forward facing.

XSokoban dataset

The backward model is learned by starting the agent in the goal poistions anwhere rewards are received. -> design reversed task: pull(not push because reverse) boxes away from the goal position (to any position). Retrieve value function $V_B$ from this whish can be used to train the forward-learning model and create backward trajectroy $T$: for a particular instance the agent is initialized at goal state(s), and a planning algorithm is used to find $T$ that maximizes $V_B$

Forward-facing value functions are $V_F$. But it also takes in \textit{hint features} based on the current state $s$ and the instance specific backward trajectory $T$. 

Novel approach to sparse-reward scenarios.
Basically mentioned that IDA* still provides the best performance
