\section{Motivation}

Sokoban occupies a distinctive position in artificial intelligence research. Unlike games such as chess or Go, where positions can be evaluated and mistakes can often be recovered from, Sokoban is a puzzle game where a wrong move can prevent the player from proceeding, often forcing a full reset. For example, a box can be permanently trapped in a corner or the player can be trapped by boxes. The irreversibility and the game's formal properties makes this game both NP-hard \cite{fryers1995sokoban} and PSPACE-complete \cite{culberson1997sokoban} placing it at the upper limits of complexity for discrete planning.

Recent deep learning agents have achieved impressive results on Sokoban. The Imagination-Augmented Agent (I2A) developed by Google achieves a solve rate of 85\% on the Boxoban benchmark \cite{NEURIPS2017_7ca66fc0}, a dataset of 9 million procedurally generated levels. However, this performance comes at a significant computational cost: agents that achieve high solve rates typically rely on large models with many millions of parameters, demanding substantial memory and processing resources. As AI systems are increasingly expected to operate under resource constraints, the question arises of whether comparable planning ability can be achieved with a substantially smaller model.

This thesis investigates that question by examining the role of input compression in neural network-guided search for Sokoban. Specifically, we evaluate whether compressing the board state representation before feeding it to the neural network heuristic can reduce the model's parameter count without a meaningful drop in solve rate.

\section{Problem Statement}

Sokoban presents two fundamental challenges that set it apart from most reinforcement learning benchmarks.

The first is irreversibility. Every action in Sokoban is potentially permanent: once a box is pushed against a wall or into a corner that is not a goal position, it cannot be retrieved. This creates deadlock states from which the only escape is a full puzzle reset. A successful agent must therefore evaluate not only the immediate effect of each action but its consequences many steps into the future, making shallow strategies inadequate.

The second challenge is sparse rewards. The agent receives no feedback signal until all boxes have been placed on their goal positions. In a $10 \times 10$ grid with multiple boxes and goals, reaching the solution purely by exploration is statistically unlikely, leaving standard reinforcement learning methods with almost no gradient signal to learn from in early training.

Beyond these, the $10 \times 10$ multi-hot grid representation raises a concern about input dimensionality. The state encodes walls, boxes, goals, and the player position across separate binary channels, producing a high-dimensional input. Standard models applied to this input may be over-parameterized for the spatial scale of the problem. This motivates an investigation into whether frequency-domain transforms such as the Discrete Cosine Transform (DCT) or learned latent representations from an autoencoder can distill the spatially relevant structure into a more compact form without losing the information needed for planning.

\section{Contributions}

This thesis makes three primary contributions.

First, we implement a DeepCubeA-style planning agent within the PuzzleJAX framework, a GPU-accelerated environment that enables training and evaluation across the full 9 million levels of the Boxoban dataset. The use of JAX and GPU parallelism makes large-scale experiments feasible within a practical time frame.

Second, we conduct a comparative evaluation of three input compression strategies applied to the Sokoban grid state before it is processed by the cost-to-go network: a convolutional neural network baseline, frequency-domain compression via the Discrete Cosine Transform, and latent-space compression via an autoencoder. For each strategy, we measure both the resulting solve rate and the total parameter count of the network, directly addressing the question of whether compression can improve parameter efficiency.
