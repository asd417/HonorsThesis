\section{PuzzleJAX}
The PuzzleJAX framework, developed by Julian Togelius et al., represents a significant shift in how puzzle-solving agents are trained and evaluated in artificial intelligence research. It is a high-performance, GPU-accelerated benchmark designed specifically to facilitate AI reasoning within combinatorial puzzle environments. By leveraging the JAX library, the framework allows for massive parallelism and end-to-end differentiability, enabling the simulation of thousands of environments simultaneously on a single accelerator.
\section{Boxoban}
The PuzzleJAX environment is utilized to load the Boxoban dataset, a collection of 9 million procedurally generated Sokoban levels released by Google. These levels are constrained to a $10\times10$ grid, providing a standardized yet vast state space for evaluating an agent's ability to generalize across millions of unique configurations.

\section{Pruning Breadth-First Search}
Generating solution trajectories for the Boxoban dataset requires a search method that is both complete and practical at scale. A standard breadth-first search applied to the full Sokoban state space is computationally intractable because many branches lead to deadlock configurations that can never reach a solution, causing the search frontier to grow unnecessarily large. To make BFS feasible, we implement a deadlock detection step that prunes any branch in which a box has been pushed into a corner position that is not a designated goal. Because such configurations are permanently unrecoverable, no solution can be found by continuing down that branch, and pruning it early avoids a large number of wasted node expansions. The resulting search produces compact, provably correct solution trajectories that serve as the primary supervision signal for training the cost-to-go network.

\section{Trajectory and Divergent Trajectory}
Training a recurrent network requires ordered sequences of states that preserve the temporal structure within a puzzle, not merely isolated state-label pairs. We therefore work with full solution trajectories produced by the pruned BFS, each consisting of a sequence of states from the initial configuration to the goal. Since puzzles vary in length, we randomly sample fixed-length sub-trajectories during training to ensure consistent sequence lengths across mini-batches. Sampling from different starting positions within a trajectory also means the network is exposed to a variety of hidden state initializations, improving its ability to generalize to mid-puzzle positions at inference time.

In addition to solution trajectories, we construct divergent trajectories to provide the network with negative training signal. A divergent trajectory is generated by branching from the solution path by a single ply — that is, taking one non-solution action from a state on the correct path — and then continuing from that state. The resulting sequence represents a plausible but ultimately incorrect path, allowing the cost-to-go network to learn to assign higher cost estimates to states that diverge from the solution.

\section{Agent Architecture}
To address the sparse reward landscape inherent in Sokoban, we implement a DeepCubeA-style architecture where Weighted A* search is guided by a deep neural network $h_\theta$ that estimates the cost-to-go from the current state to the goal. The network operates on a state $s_t$ preprocessed by a compression function $c$, outputting a scalar estimate of the remaining steps to solution:

$$\hat{h}(s_t) = h_\theta(c(s_t))$$

Node expansion during search is prioritized using the Weighted A* evaluation function:

$$f(s_t) = g(s_t) + w \cdot h_\theta(c(s_t))$$

where $g(s_t)$ is the number of steps taken from the initial state and $w \geq 1$ is a weight that trades optimality for search speed. The cost-to-go network is pretrained on solution trajectories generated via Breadth-First Search (BFS), where each state is labeled with its distance to the goal along the solution path. Following pretraining, the network is refined through bootstrapping on the A* search results to improve heuristic accuracy on unseen levels.

The solution trajectories produced by BFS exhibit a smooth sequential structure in state space, suggesting that action prediction is highly context-dependent. To capture this temporal information, we introduce a hidden state $h_t$ to provide the network with memory capacity:

$$\hat{h}(s_t), h_t = h_\theta(c(s_t), h_{t-1})$$

\section{Negative Data}
However, solution trajectory data alone is not sufficient for the cost-to-go network to reliably distinguish a productive state from a deadlock. As earlier studies have emphasized, Sokoban presents a unique challenge in which some steps are irreversible and can softlock the puzzle, leaving the agent with no path to the goal. A well-trained cost-to-go network must assign high cost estimates to such states so that A* avoids expanding them. Drawing on prior work that used explicit deadlock databases, we generate a dataset of deadlock states and non-solution steps to serve as counter-examples during network pretraining, giving the network direct supervision on what states to avoid as well as what states to seek.

\section{Input Type}
Each state of the Sokoban puzzle can either be represented in multihot tensor or a human-readable image render of the gameplay. The type of input affects the effective input compression type.

\section{Input Compression Stategies}
To assist in training of the cost-to-go network, we investigate the effect of three main input compression methods. The compressed inputs are fed through recurrent networks. All compression methods are compared against networks with no compression as a baseline.

\subsection{CNN}
A convolutional neural network processes the multi-hot grid by applying a series of learned filters that detect local spatial patterns across the board. The kernels capture geometrically local features such as box-to-wall adjacency, corridor structure, and the proximity of boxes to goals, all of which are directly relevant to planning. By preserving the full spatial topology of the grid throughout processing, the CNN serves as the baseline compression method, reducing the input to a compact feature map while retaining the relational structure of the board state.

\subsection{Autoencoder}
An autoencoder compresses the board state into a low-dimensional latent vector by training an encoder-decoder pair end-to-end. The encoder maps the full multi-hot grid to a compact bottleneck representation, while the decoder attempts to reconstruct the original state from that representation. Because the network must preserve sufficient information to enable reconstruction, the bottleneck tends to capture the most statistically regular features of the Boxoban distribution, including the positions of boxes and goals and the overall wall layout. Unlike the CNN baseline, the autoencoder performs explicit dimensionality reduction: the cost-to-go network operates on the compressed latent vector rather than on the full grid, which is expected to reduce the overall parameter count.

\subsection{DCT}
The Discrete Cosine Transform (DCT) converts the spatial grid state into the frequency domain, decomposing the board into a weighted sum of cosine basis functions at different spatial frequencies. Low-frequency coefficients capture the broad spatial structure of the board — the overall layout of walls and the approximate positions of boxes and goals — while high-frequency coefficients encode fine-grained local detail. By retaining only the top-$k$ coefficients by magnitude and discarding the rest, DCT compression reduces the input dimensionality while preserving the global structure that is most informative for long-horizon planning. This approach is analogous to its use in image compression standards such as JPEG, and because the transform is fixed rather than learned, it introduces no additional training parameters.
