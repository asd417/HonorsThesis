\section{PuzzleJAX}
The PuzzleJAX framework, developed by Julian Togelius et al., represents a significant shift in how puzzle-solving agents are trained and evaluated in artificial intelligence research. It is a high-performance, GPU-accelerated benchmark designed specifically to facilitate AI reasoning within combinatorial puzzle environments. By leveraging the JAX library, the framework allows for massive parallelism and end-to-end differentiability, enabling the simulation of thousands of environments simultaneously on a single accelerator.
\section{Boxoban}
The PuzzleJAX environment is utilized to load the Boxoban dataset, a collection of 9 million procedurally generated Sokoban levels released by Google. These levels are constrained to a $10\times10$ grid, providing a standardized yet vast state space for evaluating an agent's ability to generalize across millions of unique configurations.

\section{Agent Architecture}
To address the sparse reward landscape inherent in Sokoban, we implement an AlphaGo-style architecture where tree search is guided by a policy network ($\pi_\theta$) and a value network ($V_\phi$). These functions operate on a state $s_t$ that has been preprocessed by a compression function $c$. The policy network outputs action logits $a_t$ to prioritize the search space, while the value network provides a scalar $v_t$ estimating the utility of the current state:

$$a_t = \pi_\theta(c(s_t))$$

$$v_t = V_\phi(c(s_t))$$

The agent is initialized through supervised learning on solution trajectories generated via Breadth-First Search (BFS). These trajectories consist of state-action pairs that define the optimal path to the goal. Following pretraining, the value network is refined using reinforcement learning and search bootstrapping to improve efficiency on unseen levels.

The analysis indicates that steps within a single puzzle are more closely clustered than those across different puzzles, largely due to the persistence of static wall structures in the multi-hot input layers. More importantly, the smooth curve formed from the start to the goal state suggests that action prediction is highly context-dependent. To capture this temporal information, we introduce a hidden state $h_t$ to provide the networks with memory capacity:

$$a_t, h_t = \pi_\theta(c(s_t), h_{t-1})$$

$$v_t, h_t = V_\phi(c(s_t), h_{t-1})$$
