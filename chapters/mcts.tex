\section{Monte Carlo Tree Search}
Monte Carlo Tree Search is a heuristic search algorithm used for planning in a discrete action space. \cite{coulom2008monte} Unlike A*, which relies on fixed heuristic function to evaluate states, MCTS estimates the score of the state by performing simulations to evaluate how often a particular move leads to a win or solution.

The evaluation process begins at the current state, from which the tree expands with all possible actions. From each expanded action, the agent randomly performs multiple rollouts, which are the process of playing a full environment from the current state. Probabilistically, the random rollout will tell how good the selected action is based on the average returned score. The best action is selected with this method and with the newly selected action, the tree expands again. 

To ensure this expansion is both efficient and thorough, standard MCTS implementations utilize the Upper Confidence Bound (UCB) to prioritize high-reward leaves. The chosen action $A_i$ at node $i$ is the action with the maximum UCB score calculated by average win count $\frac{w_i}{s_i}$ added to exploration parameter $c$ multiplied by the natural log of parent node's total number of simulations $s_p$ divided by total number of simulation $s_i$

$$A_i = argmax_a(\frac{w_i}{s_i} + c\sqrt{\frac{ln(s_p)}{s_i}})$$

The equation is based on concepts from the Multi-Armed Bandit (MAB) problem, a framework in probability that addresses the exploration-exploitation tradeoff. The average win count biases towards higher score actions and continues to search for the branch with higher score while the second term (exploration) spreads the selection to more than one node path. 

However, while this works in many scenarios, traditional MCTS faces the sparse reward problem in complex problems such as Go. Because the environment consists of long term planning with only few moves returning reward based on specific contexts, a random rollout is statistically unlikely to reach the solution state where all the boxes are on goals. Consequently, the average win count $\frac{w_i}{s_i}$ is nearly zero for all branches except one or two, leaving the agent with no signal to guide its search.

This limitation motivated a shift toward neural-network based agents which can replace the traditional UCB value with a learned model and lead the search based on patterns that are unclear from the current state.

With the introduction of neural networks as a function that replace the UCB value, neural network-based agents can now search the action space that would provide the best outcome after several actions.

AlphaGo \cite{silver2017mastering} was one of the most prominent demonstration of combining MCTS with deep neural networks. By replacing  random rollouts and UCB with two separate deep neural networks, policy network and value network, the agent was able to successfully play against competitive players in a game of GO where the branching factor is so high that MCTS loses its proficiency.
